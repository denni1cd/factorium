## Example and review expectations

Every substantive art recommendation must include a real representative generated/edited example using an actually available toolchain and two independent adversarial Work subagents asking "Is this realistic?". The developer decides whether to adopt the recommendation.

Gameplay visual testing is optional; when not performed, finished assets should be classified "Visually reviewed, not seen in gameplay" after applicable technical checks and actual visual inspection.
